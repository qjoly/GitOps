OctoDoctor

OctoDoctor checks Argo CD Applications, ApplicationSets, AppProjects and the argocd-* ConfigMaps/Secrets against a set of rules. It is read-only and pinned in mise.toml.

Running it

mise run octodoctor:scan            # manifests tracked in git
mise run octodoctor:scan mocha      # a single directory
mise run octodoctor:export doppio   # live Argo CD, through a kube context

Both tasks print the path of index.html. Reports and exports go to $TMPDIR/octodoctor (override with OCTODOCTOR_OUT), never into the repo. Secret values are redacted by the export.

Prefer export: the repo scan misses things.

  • Only the first document of a multi-document YAML file is read, so the ApplicationSets in turing/bootstrap/bootstrap.yml and doppio/bootstrap/bootstrap.yml are not seen.
  • Applications generated by the ApplicationSets don't exist in git.
  • omni-turing needs an OIDC browser login before export works.

First analysis (2026-11-15, v0.5.0)

Rule Severity Hits (mocha / doppio, live) Verdict
R05 AppProject sourceRepos: '*' high default / default Accepted: single tenant, everything runs in default.
R17 Helm parameters high external-dns, external-secrets / external-secrets Fixed: moved to values, rendered output unchanged. Turing had the same two.
R22 No webhook in argocd-secret medium 1 / 1 Fixed on mocha: the GitHub webhook already existed, but Argo CD accepted unsigned calls. Its secret now comes from kv/argocd (webhook_github_secret).
R06 No manifest-generate-paths medium 98 / 25 Only useful with R22. Then set it in the ApplicationSet templates.
R14 prune: true medium 22 / 22 Ignored: intended.
R15 Inline Helm values medium 35 / 10 Ignored: values live next to the Application in git anyway.
R19 targetRevision not HEAD medium common, maintenant / common False positive: main for common, upstream tag pin for maintenant (and spegel on turing).
R25/R26 Multi-source with several charts medium authentik, proxyauthk8s / – Ignored: chart + its CRDs/provisioner + local manifests, one lifecycle.

Passed: no anonymous access, sync timeouts, automated sync, no kustomize overrides. Inactive: no Image Updater, matrix/merge generators or PR generators.
